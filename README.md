# 中国传统门神画数字展览馆

这是一个融合传统文化与现代科技的数字展览项目，致力于通过创新的展示方式让更多人了解和欣赏中国传统门神画艺术。本项目采用最新的 Web 技术，打造沉浸式的在线展览体验。

## 🌟 项目特色

- **数字化展示**: 通过3D虚拟展厅，为观众提供沉浸式的观展体验
- **AI修复技术**: 运用人工智能技术修复和重现珍贵的门神画作品
- **互动体验**: 提供在线创作平台，让观众参与门神画创作
- **文化传承**: 系统展示门神画的历史发展、地域特色和艺术价值

## 🎨 展览内容

### 1. 虚拟展厅
- 3D展示空间，四面展墙布局
- 高清画作展示，自由漫游体验
- 画作信息实时展示
- 沉浸式观展体验

### 2. 精品展示
- 绿云巨幅门神（清代，中国美术馆藏）
- 钟馗门神（明代，纸本设色）
- 武门神：神荼郁垒（清代，国家图书馆藏）
- 木刻年画《军民合作》（1944年，严涵）

### 3. 地域特色
- 山东杨家埠：浓艳色彩，生动民间风格
- 天津杨柳青：色彩艳丽，构图严谨
- 河南朱仙镇：浓郁乡土气息
- 江苏桃花坞：精细工艺，典雅风格
- 四川绵竹：巴蜀特色，色彩绚丽

## 🛠️ 技术栈

- **前端框架**: Next.js 13+
- **样式方案**: TailwindCSS
- **3D渲染**: Three.js + React Three Fiber
- **动画效果**: Framer Motion
- **AI功能**: TensorFlow.js

## 📦 安装和运行

1. 克隆项目
```bash
git clone https://github.com/your-username/chinese-door-god-exhibition.git
cd chinese-door-god-exhibition
```

2. 安装依赖
```bash
npm install
```

3. 启动开发服务器
```bash
npm run dev
```

4. 在浏览器中访问
```
http://localhost:3000
```

## 🗂️ 项目结构

src/
